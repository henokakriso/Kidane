# Kidane — AI Micro-Drone System

Kidane is an autonomous micro-drone research and development project focused
on intelligent aerial systems.

It explores compact drones equipped with onboard intelligence, sensing,
navigation, communication, and coordinated autonomous behavior. Long-term
applications include infrastructure inspection, environmental observation,
emergency response, search and rescue, agricultural monitoring, and other
civilian uses where small autonomous aerial systems provide useful
information.

**Core vision:** Develop Ethiopian capabilities in intelligent autonomous
aerial technology.

Part of [Project ARWE](https://github.com/henokakriso).
